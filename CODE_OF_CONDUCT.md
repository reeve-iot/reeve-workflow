# Code of conduct

## Our standard

Be respectful, assume good faith and keep criticism aimed at code rather than people. Disagreement is expected and
useful; contempt is not.

Unacceptable behaviour includes harassment, personal or demeaning attacks, publishing others' private information,
and sustained disruption of discussions.

## Scope

This applies in every project space (issues, pull requests, commit messages) and when representing the project
elsewhere.

## Enforcement

Report concerns privately through GitHub private vulnerability reporting (the repository's Security tab, "Report a
vulnerability") or by contacting a maintainer directly on GitHub. Reports are handled confidentially. Maintainers may
edit or remove contributions, and may temporarily or permanently exclude anyone whose behaviour they judge
inappropriate; they will say why when they do.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
